## Overview

Movement Core is the foundational repository for the Movement ecosystem — a modular blockchain infrastructure stack built around MoveVM, governance systems, and cross-chain liquidity architecture.

The ecosystem is designed as a multi-layer system rather than a single monolithic entity.

---
